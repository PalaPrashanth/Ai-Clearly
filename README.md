AI, Clearly — Educational AI Guide

A beginner-friendly website that explains Artificial Intelligence (AI) in simple, clear language.

🌐 Live Website: https://ai-clearly.pages.dev/

Features

- 🤖 Clear explanations of AI concepts
- ✍️ Interactive Prompt Builder
- 🧠 Interactive AI Quiz
- ✅ Learning Checklist
- 🛠️ Curated list of popular AI tools
- 🔌 Simple API explanation and simulation
- 📚 Beginner-friendly AI learning resources
- 📱 Responsive design for desktop and mobile

About

AI, Clearly is an educational website designed to help beginners understand Artificial Intelligence without complicated technical language.

The website provides simple explanations, interactive learning activities, and practical examples to make learning AI easier and more engaging.

Technology

This is a lightweight static website built with:

- HTML
- CSS
- JavaScript

No framework or build system is required.

Deployment

The website is hosted using Cloudflare Pages and connected directly to the GitHub repository.

Any changes pushed to the "main" branch can be automatically deployed to the live website.

Repository Structure

Ai-Clearly/

Getting Started

You can run the website locally by opening "index.html" in a web browser.

No installation or build process is required.
