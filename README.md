# AI, Clearly — Educational AI Guide

Beginner-friendly website that explains AI concepts in plain English.

**Live demo:** [https://d4clearns-ai.netlify.app/](https://d4clearns-ai.netlify.app/)

## Features
- Clear explanations of AI basics
- Interactive prompt builder
- Quiz & checklist
- Curated list of popular AI tools
- API explanation with simple simulation

Built using AI coding tools, then refined and deployed on Netlify.
